# calendar（IoT化予定※）


＜機能＞
・ Raspberry Pi等をサーバーとして、無線Lanのネットワーク環境で動作します。
・ スマホやPCの各デバイスでログイン/ログアウトと、予定の登録・削除・閲覧が可能です。

＜セキュリティ＞
・ Flask標準のセッションクッキーとランダムな暗号鍵を設定し、ログイン中のユーザー以外のスケジュール閲覧・登録を防止
・ SQLite3で外部キーを有効化し、親テーブルusersのuser_id列にないIDからの登録を無効化（未登録ユーザーは予定登録ができません）
・ 各ユーザーのパスワードを暗号化（ハッシュ化）し、ハッカーによる解析を防止



※開発中の機能
・ Raspberry Piを玄関に設置し、人感センサーで出発・帰宅時を検知してブザーで通知音を鳴らし、LCDモニタに今日の予定を表示することで、うっかり予定を忘れるのを防ぐ。
