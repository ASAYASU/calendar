# IoTカレンダーアプリ


### ＜機能＞
・ Raspberry PiやArduino等のOSが入ったシングルボードコンピュータをサーバーとして、無線Lanのネットワーク環境で動作します。<br>
・ スマホやPCの各デバイスでログイン/ログアウトと、予定の登録・削除・閲覧が可能です。<br>
<br>
### ＜セキュリティ＞
・ Flask標準のセッションクッキーとランダムな暗号鍵を設定し、ログイン中のユーザー以外のスケジュール閲覧・登録を防止<br>
・ SQLite3で外部キーを有効化し、親テーブルusersのuser_id列にないIDからの登録を無効化（未登録ユーザーは予定登録ができません）<br>
・ 各ユーザーのパスワードを暗号化（ハッシュ化)し、ハッカーによる解析を防止<br>
<br>
### ＜フォルダ構成＞
　ご使用時はPythonとFlaskとSQLite3をサーバー機器にインストールし、下記の通り各ファイルをフォルダ上に配置してください。<br>
<br>
<pre>

</pre>
